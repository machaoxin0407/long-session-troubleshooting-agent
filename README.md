# 面向设备故障排查的长会话智能体

面向设备售后长轮次故障排查，结合知识检索、会话记忆与上下文管理，重点解决长对话中的历史事实丢失、排障状态混淆及回答来源不清问题。

本仓库公开核心源码、相关测试及可复核的合成评测数据。私有部署配置、原始服务器记录、真实用户对话、数据库和运行缓存保存在私有工作区，不纳入公开发布。

## 技术栈

Python · FastAPI · LLM Tool Calling · RAG · BM25 · Embedding · SQLite

## 核心能力

- **Agent 与知识检索：** 支持客服与技术问答路由、工具调用和产品手册检索，返回可追溯的图文及视频关联证据。
- **长会话记忆：** 将近期窗口、结构化摘要与原文回查结合，保留历史事实的来源轮次；支持单层回查、全层树检索及逐层树检索。
- **上下文可靠性：** 统一估算系统提示、工具定义、历史、检索证据及输出预留，按优先级裁剪，并保护工具调用配对、图片和来源标识。摘要校验失败时回退原文，超预算请求提前拦截，失败回答不写入会话状态。
- **会话持久化：** 使用 SQLite 保存同一会话状态，支持重启恢复、会话隔离、清空及1小时 TTL，不提供跨会话永久记忆。

## 实验结果与设计取舍

### 长会话记忆对照

基于56组冻结合成会话，覆盖40、80、160轮历史，在相同问题、回答模型和上下文预算下开展五策略配对评测，共280次真实模型主问答；另完成70次重复及28次消融实验。

| 记忆策略 | 自动规则通过数 | 自动规则通过率 |
|---|---:|---:|
| 滑动窗口 | 15/56 | 26.8% |
| 滚动摘要＋窗口 | 12/56 | 21.4% |
| 结构化摘要＋原文回查 | 45/56 | 80.4% |
| 全层树检索 | 46/56 | 82.1% |
| 逐层树检索 | 47/56 | 83.9% |

结构化摘要＋原文回查方案（含降级回退）较窗口基线提高 **53.6个百分点**。45次通过中，正常摘要路径通过2次、降级路径通过43次，衡量的是整个方案及其容错机制，不能归因于模型摘要本身。

树结构相对单层回查的配对差异区间包含0，当前测试未显示明确额外增益；综合效果、构建开销及维护复杂度，优先推荐单层回查方案。这不代表树结构在其他数据和任务上无效。

以上为合成历史上的预设自动规则结果，实际回答未进行独立人工语义验收，不代表真实用户语义正确率或生产成功率。重复实验不增加独立样本数。

### 独立视频检索实验

在100条冻结查询的独立历史视频检索实验中，以加权 RRF 融合 BM25关键词检索、文本向量检索及视觉向量检索的候选排序：

| 方法 | nDCG@10 |
|---|---:|
| BM25 | 0.469 |
| 三路检索排序融合 | 0.647 |

nDCG@10相对提升约 **37.9%**，按原始指标0.469299与0.646976计算。该结果属于独立离线检索实验，不是客服 Agent 的整体问答效果，也不证明所有模态共享同一向量空间。

## 工程验证

- 已有全量本地回归记录为3883项通过、1项跳过，包含参数化测试实例，不等于真实模型问答次数。
- 完成独立 FastAPI 服务部署及隔离环境验收，验证双聊天接口、会话隔离、重启恢复及异常场景下的状态一致性。
- 部署验证为小规模合成验收，不据此推导生产可用性、高并发能力或完整 Agent 端到端时延。

## 项目价值

围绕长轮次故障排查建立“实现—基线对照—错误与成本分析”的验证流程，用实验判断额外架构复杂度是否值得引入，并保留对失败、降级和未完成验收的说明。


## 公开内容与运行方式

- `agent.py`、`api_server.py`、`grounding_*.py`：Agent 路由、工具调用与回答证据约束。
- `session_*.py`、`request_context.py`、`model_attempts.py`：会话记忆、上下文预算及评测请求账本。
- `video_rag/`：视频证据处理与三路候选排序融合实现。
- `tests/`：会话记忆、上下文预算、评测工具和部署保护的离线测试子集。
- [公开评测证据](reports/public_long_session_20261008/README.md)：70组冻结合成会话、448条开发/主评测/重复/消融回答及其可见上下文、自动规则评分和文件哈希。

推荐 Python 3.11。在自己的环境中安装运行与开发依赖：

```bash
python -m pip install -r requirements.txt
python -m pip install -r requirements-dev.txt
```

复核已归档结果，无需配置模型凭据，也不会发起模型请求：

```bash
python deploy/export_public_session_evidence.py --verify reports/public_long_session_20261008
python -m pytest tests -q
```

创建独立的新实验目录，准备合成案例和核对表，不覆盖已冻结数据：

```bash
python benchmark_session_memory.py --experiment --phase prepare --output reports/my_experiment
```

在线问答与真实模型新实验需要自行配置 `.env.example` 中的模型和 API 认证变量。产品手册、预构建手册索引、视频原文件及生产向量索引未随此仓库提供：请使用自己有权使用的手册数据，通过 `parse_manuals.py` 与 `build_retrieval_index.py` 构建知识库；视频功能另需自己的素材、索引及可选依赖。缺少这些资源时，不能把接口启动或离线测试通过当作完整知识检索链路验收。

仅调试本机接口时，可显式使用 development profile、允许视频检索降级，并绑定回环地址；这不等于三路检索生产验收：

```bash
VIDEO_RUNTIME_PROFILE=development VIDEO_REQUIRE_EXACT_MODE=0 python -m uvicorn api_server:app --host 127.0.0.1 --port 19495 --workers 1
```

上面的环境变量写法适用于 Bash；PowerShell 请通过 `$env:变量名` 设置。本次公开子集已在独立目录通过133项离线测试；前文3883项是完整私有工作区的既有回归记录，两者不混同。网页脚本测试可选依赖Node.js，缺少时会跳过相应用例。冻结源码与数据的字节哈希保留在公开清单中，私有仓库的旧提交历史未并入此仓库。
